# Insta Video Controller

Firefox extension (Manifest V3) that adds real video controls to Instagram web and Android.

## Features
- Seek bar with current time and duration
- Play/pause, skip back/forward (5, 10, 15, 30s)
- Playback speed 0.25x–3x, remembered
- Volume and mute remembered
- Loop toggle and Picture-in-Picture
- Keyboard shortcuts

## Install
Load unpacked in Firefox via `about:debugging` or submit to AMO.
